> setup // einmal pro Gerät

Deine Daten werden in einem privaten Gist in deinem GitHub-Konto gespeichert. So sind sie auf jedem Gerät gleich. Dafür braucht die App einen GitHub-Token, der nur Gists lesen/schreiben darf.

  1. Öffne github.com/settings/tokens/new (Scope gist ist schon angehakt).
  2. Ablaufdatum wählen (z. B. „No expiration“) und Generate token klicken.
  3. Token hier einfügen. Er bleibt nur auf diesem Gerät gespeichert.
